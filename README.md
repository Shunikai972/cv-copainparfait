# cv-copainparfait

Un CV de candidature amoureuse beaucoup trop sérieusement développé.

## Stack

- Vue 3
- Vite
- CSS natif
- GitHub Pages

## Au programme

- intro animée façon chargement de dossier candidat
- design premium responsive mobile
- thème sombre / clair
- galerie photo
- compétences, valeurs, statistiques et FAQ
- `Known Issues` et `Features`
- section poésie
- shortlist interactive
- easter egg félin et Konami Code
- CV amoureux PDF réellement téléchargeable

## Développement

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

Le dépôt contient un workflow GitHub Actions qui compile et déploie automatiquement le site sur GitHub Pages à chaque push sur `main`.
